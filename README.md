# Finocube

Elevest franchise partner website for [finocube.com](https://finocube.com).

Built from the Invest Strategy web codebase, restyled to match [Elevest](https://www.elevest.in/) and rebranded for Finocube.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Live site (GitHub Pages)

Every push to `main` deploys automatically via `.github/workflows/deployment.yaml`.

**URL:** https://aseempsri.github.io/finocube/

Enable Pages once in repo **Settings → Pages → Build and deployment → Source: GitHub Actions**.
